# Smart Reservoir Oxygen Balancing Robot System

## Overview

The Smart Reservoir Oxygen Balancing Robot System is an AI-driven simulation designed to monitor and maintain optimal dissolved oxygen (DO) levels in aquatic environments. It demonstrates how intelligent robotic agents can automate oxygen regulation to support sustainable aquaculture and improve fish health.

---

## Key Features

* Autonomous scout robot for oxygen detection
* Base robot for automated aeration
* Real-time dissolved oxygen monitoring
* Fish behavior simulation based on oxygen levels
* Dynamic plant movement simulation
* Live graph visualization of average DO levels

---

## Supported Fish Types

* Tilapia
* Carp
* Catfish

## How It Works

The system uses a scout robot to continuously monitor oxygen levels across different regions of the reservoir. When a low-oxygen zone is detected, the base robot is deployed to that location to perform aeration and restore optimal conditions. The system dynamically updates the environment and visualizes data in real time.
